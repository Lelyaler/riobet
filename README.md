# Riobet Casino — Мобильный лендинг & AMP версия

Высокопроизводительный мобильный лендинг для онлайн-казино **Riobet**, полностью сверстанный на чистом HTML5, Vanilla CSS и JavaScript в строгом соответствии с требованиями **Mobile-First**. 

В состав проекта входит стандартная версия (`index.html`) и полностью валидированная Google AMP версия (`index.amp.html`).

---

## 🚀 Особенности и преимущества проекта

* **Mobile-First подход**: Страница идеально адаптирована под любые мобильные устройства и планшеты.
* **Без CSS-фреймворков**: Весь макет построен на чистом CSS (Flexbox + CSS Grid). Никаких Bootstrap, Tailwind или сторонних конструкторов.
* **Чистый JavaScript**: Взаимодействие с пользователем (копирование промокода, мобильное меню, аккордеоны FAQ) реализовано на чистом JS без jQuery.
* **Оптимизация графики**: Все изображения переведены в формат WebP, сжаты и адаптированы под Retina-экраны. Используется элемент `<picture>` с источниками `720w` для мобильных устройств.
* **Высокая скорость загрузки**: Предзагрузка ключевых LCP-ассетов (`<link rel="preload">`), минифицированный CSS, отсутствие тяжелых зависимостей.
* **Полноценная AMP-версия (`index.amp.html`)**: Включает компоненты `<amp-carousel>`, `<amp-accordion>`, а также интерактивный `<amp-script>` для моментального копирования промокода.
* **Доступность (Accessibility & SEO)**: Строгая и последовательная иерархия заголовков (`H1 ➔ H2 ➔ H3`), увеличенные области нажатий для тач-скринов (Touch Targets >= 48px), микроразметка.

## 📦 Структура и основные блоки

1. **Header (Шапка)**:
   * Фиксированное верхнее меню с логотипом, кнопками «Вход» / «Регистрация» и кнопкой мобильного меню.
   * Суб-навигация с быстрым переходом по разделам и WebP-иконками.
2. **Hero Slider (Главный баннер)**:
   * Адаптивный слайдер с высокими показателями LCP и подгрузкой легких мобильных графических ассетов.
3. **Promo Offer Section (Конверсионный блок с промокодом)**:
   * Элемент с эксклюзивным промокодом **`RIO2026`**, интерактивным копированием в буфер обмена (с отображением галочки `✓`) и раскрывающимися условиями бонуса.
4. **Content & Specs (Контент и таблицы)**:
   * Раздел игровых слотов и фильтрации.
   * Адаптивные таблицы с вейджерами, бонусами и характеристиками казино.
   * FAQ-аккордеон с частыми вопросами.
5. **Footer (Подвал)**:
   * Лицензионная информация, ссылки на правила, логотипы партнеров и провайдеров.

## 🛠 Технический стек

* **HTML5**: Семантическая верстка (`<header>`, `<main>`, `<section>`, `<article>`, `<figure>`, `<picture>`, `<footer>`).
* **CSS3**: Ванильный CSS, CSS Variables, Flexbox, CSS Grid, Media Queries, `@media (max-width: 768px)`.
* **JavaScript (ES6+)**: `Clipboard API`, Event Listeners, работа с DOM без сторонних библиотек.
* **Google AMP**: AMP Boilerplate, `<amp-carousel>`, `<amp-script>`, `<amp-accordion>`.

## 💻 Локальный запуск

Для локального просмотра проекта достаточно запустить любой статический веб-сервер.

### Запуск через Python:
```bash
python3 -m http.server 8000
```

После этого открывайте в браузере:
* **Основная версия**: [http://localhost:8000/index.html](http://localhost:8000/index.html)
* **AMP версия**: [http://localhost:8000/index.amp.html](http://localhost:8000/index.amp.html)
